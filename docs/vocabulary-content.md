# 词库扩充：内容优先

目标是让家长能搜到要学的词并直接选择；阶段和分类不是本轮目标。此前未提交的分级界面、阶段包、按所选资源组合下载协议均已还原，不以这些能力作为扩词前提。

## 本轮交付

- 总计3038张词卡，来自1168张原图文卡和1870张新增词卡。两轮补图后，有图1690张、仍需情境设计1348张；所有词卡均有释义、双语例句和音频。
- 小学目标表505/505个主词条能对应应用卡片；`a/an`一个来源条目对应两张卡。高中主表对应2531/3099行，尚有568行未对应。仅统计拼写与词表别名，不代表全部义项或考试能力。
- 来源URL、哈希和提取说明在 `data/vocabulary/sources.json`。高中附录声明3100词、主表提取3099行的差异保留，不补造词条。原始PDF缓存保留在本地，未打包到网站。
- 没有阶段索引，也没有阶段筛选或分级下载入口。家长选词页已恢复原有搜索框与主题下拉框并排布局；看图学词页已按用户要求恢复原主题按钮展示，760px及以下沿用原来的直接下拉适配。
- 下载沿用原有全量包与续传、去重、版本复用逻辑；构建仅将新增词卡资源加入全量清单，未修改 Service Worker 或下载界面。

## 内容维护

1. 首批226词维护于 `data/vocabulary/primary-context.tsv`（ID、释义、英文例句、中文翻译）和 `context-parts-of-speech.json`（本例词性）。后续1644词维护于 `extended-context.json`：每条用ID绑定释义、本例词性、双语例句及可选署名。新词不覆盖既有ID。
2. `node scripts/compile-context-vocabulary.mjs` 同时读取两批内容，生成 `app/context-words.js`。`display`维护 I、China 等大小写，`spoken`维护 Mr 等称呼读音文本。
3. `node scripts/generate-picture-audio.mjs` 用现有本地Kokoro模型补生成音频。依据文本/模型签名复用缓存；改过发音或例句的词需重新生成，不能只保留旧文件。
4. `npm run build` 会重新编译内容、校验双语例句和本地PCM16音频、生成下载清单。
5. `node scripts/audit-vocabulary.mjs` 更新后台的目标拼写索引及覆盖差集，不生成前端分类。

`pictureCue`让无图词使用语境听读，避免错误生成识图题或自动标记掌握。句义必须对应具体英文原句。旧版自定义文本迁移只保留原有词卡，新增词由家长显式选择，避免词库扩充悄悄改变当前学习范围。

## 边界和剩余工作

新增内容包含项目编写例句和开放语料，音频为本地合成，未经过教师逐项审核。高频多义词只覆盖当前例句所示用法。初高中缺词、更多义项/搭配和具体名词的准确配图仍需继续补充；不要用字典释义加通用模板句虚报完整学习卡。

后续优先补内容，不再先扩展分类或下载产品设计。真实iPad硬件及逐条语音教学质量仍需验收。

- 每条用法和释义经模型逐项检查；不准确、仅命中其他词义或不合适的例句已修订/重写。繁体翻译使用 OpenCC 转为简体并修订。原始来源证据不改写，`adapted`标识是否转换或改写。
- 另125条为项目编写，补充常用缺词和英美拼写。此批释义与词性按例句编写，未直接搬用整段字典释义。`found`采用“创立”，`lay`采用“放置”，避免把屈折形式当作目标词义。

- 维持原来的搜索、勾选和全量下载；新增媒体只进入原有全量清单，不加入分类页面或分级下载协议。

已进行的自动检查不能证明逐句教学质量、所有发音正确或真实iPad硬件体验。每词当前只提供一个具体用法；更多义项、剩余高中主词条、名词插图和教师逐条听读验收仍未完成。

本次构建全量离线包约577 MiB（7,481个资源）。自动安装清单35项，不含WAV音频；新增3,288段音频均已生成，PCM16/单声道、时长和文本签名检查通过。

## 发布范围与导入变体（2026-10-31）

原始 `WORDS` 保留全部 3,038 条素材，供来源追溯、音频与旧记录兼容使用；不是孩子端词库。`CATALOG_WORDS` 按 `app/word-aliases.js` 的审核映射合并重复写法；`READY_WORDS` 只包含有图片的规范词卡，供孩子端所有练习和家长新选使用。`PENDING_WORDS` 保存无图片的规范词卡，补图后自动进入可学习范围。不要直接删除待完善词的选词或掌握记录。

本次审核导入源中的多写法条目，结果保存在 `data/vocabulary/import-variant-review.json`。仅合并已确认的同义拼写变体和明确缩写，例如 `per cent → percent`、`colour → color`、`bicycle → bike`。不同词形、性别、称呼或独立同义词（如 `be/am/are/is`、`actor/actress`、`father/dad`）仍分别保留；不能按括号、空格或斜杠一刀切。复合词如 `ice cream` 继续保留。

当前合并 32 张重复词卡，剩余 3,006 张规范卡：1,674 张可学习，1,332 张待完善。别名可搜索到规范卡；选择记录按规范 ID 去重并保留首次出现顺序，掌握状态取已有已掌握状态，练习证据不相加，避免误判自动掌握。旧存储在读取时兼容，后续用户操作保存规范 ID。

继续导入时应审核新变体并更新映射及审核表。`audit-vocabulary.mjs` 为每个源写法输出 `canonicalId`，素材文件仍保留原始 ID，禁止凭字符串相似度自动合并。可学习与待完善计数由程序计算，不以本文快照作为运行时常量。

家长小角提供默认收起的“查看待完善单词”入口，支持中英文及别名搜索和分页。列表为只读文本卡片，搜索和页码与可学习词库独立；不提供单选或批量选入操作，也不写入选择或掌握记录。

## 离线分类更新（2026-10-31）

此节取代前文历史阶段的全量下载范围：家长界面展示“词卡图片、单词读音、例句读音、其他内容”四类，并保留全部下载。前三类只从 `READY_WORDS` 生成；待完善词和别名重复词的图片、单词音频和句子音频不进入下载清单。其他内容保留字母、故事、对话、发音对照及来源说明，其学习所需图片和例词音频可能与前三类重叠；全部包取URL并集，不重复下载或计费存储。

当前构建快照：图片9.68 MiB、单词读音118.07 MiB、例句读音173.13 MiB、其他内容27.99 MiB；去重后共326.99 MiB、5,257个文件。旧主题包ID继续兼容，但主题包也限定为已发布词卡。旧缓存不主动删除，更新按资源哈希复用仍在新清单内的文件；需要释放旧素材时可使用“清理全部素材”。完整缓存与下载保留状态分别计算，避免把可淘汰的浏览缓存误标成已下载。

每类提供“下载”和“清理”，底部为“下载全部素材”和“清理全部素材”。分类清理会取消该类的下载保留，并删除未被其他已下载分类引用的缓存文件（含旧构建中复用的副本）；下载过全部时先拆成其余分类的保留记录。共用资源仍显示为已保存，没有可回收文件时清理按钮置灰。全部清理则移除所有素材缓存及下载保留记录，保留学习记录和设置。

## 简化更新策略（2026-10-31）

本节取代上述旧主题包兼容和跨版本复用规则：构建清单只保留 pictures、word-audio、sentence-audio、other、all。新版启用（Service Worker activate）时删除本站路径下旧版本的页面缓存、素材缓存和下载元数据；新版本不读取旧下载记录，不复用旧版文件。所需素材需重新下载。同版本内的暂停续传、分类共享文件保护保持不变。清理仅针对 Cache Storage，不操作 localStorage 或 IndexedDB，因此选词、掌握记录和自定义音频保留。
