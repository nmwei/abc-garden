## 背景、目标与非目标

目标按优先级排列：

1. 国内设备能稳定访问正式域名，保住现有本机学习数据。
2. 家长配置和学习存档可恢复：换设备或清除网站数据后，重新登录可找回最后一次成功同步的记录。
3. 保留离线学习体验；网络或账号服务故障不阻断已有本机内容的练习。
4. 新版本以自有服务器为正式发布目标，GitHub 继续用于源码托管。

已确认范围：先在 ABC 打通完整闭环，后续接入阅读与数学；产品目标为公众可自助注册，不采用邀请制。上线前的自家设备验收是发布测试，不改变公开注册目标。

建议继续允许游客在本机学习；家长在需要云端保存时注册/登录，孩子不必为开始练习单独建立账号。公开注册仅开放账号申请，个人存档仍保持私有。

首期不包括：多人家庭权限管理、复杂自动合并、营销获客体系、收费、排行榜、行为分析平台、录音和作品云盘、服务器实时 TTS、前端框架重写。公开注册、自助账号恢复与注销属于首期。微信是否首期接入取决于实际权限和设备验证，不作为迁站前提。

## 关键设计决策

### D1. 先完成三站国内部署，保留旧站数据入口，再完成账号云存档

用户已要求把三站正式部署及发布脚本修改作为第一步。静态站上线不依赖账号或导出工具；当前保留旧站可访问性和旧域名存储，不关闭旧 Pages。导出/导入后续独立实现；新站不能自动读取旧站数据，旧主屏幕图标不会自动变成新站。

按照用户最新决定，三个仓库的发布脚本改为 ECS，后续不再向 GitHub Pages 发布，也没有为迁移额外发布旧站维护版本。GitHub 继续托管源码，源码推送和服务器发布相互独立。

### D2. 一套家长身份，多科目存档

业务主键使用内部账号 ID，微信等作为可绑定的登录凭证，不把 OpenID 当全部业务数据的主键。存档按账号、学习档案、科目隔离；首期一个默认学习档案即可，多孩子切换与多家长共享需要另行确认。

三个花园可共享同一来源下的账号服务及 `/api/`。本次沿用并启用了 `https://nmwei.cn/abc-garden/`、`/reading-garden/`、`/math-garden/`，根路径提供个人项目入口；`www` 跳转到主域名。

同源子目录并非安全隔离。采用主域名方案时，未来不受同等信任的实验站应放独立子域名；会话 Cookie 不扩散到整个父域。实际 PWA 的登录共享能力需真机验证，不能仅凭相同域名承诺一次登录所有主屏幕应用。

### D3. Node 后端同仓可行，独立运行与持久化

建议 ABC 内新增 `server/`，初期承载共享账号及存档 API；业务按科目分区，不让阅读/数学依赖 ABC 的学习逻辑。前端继续沿用现有技术，`garden-hosting` 维护服务器运行与发布配置。

建议初期结构：Nginx 提供静态文件和 HTTPS，将 `/api/` 反代到仅本机监听的 Node 服务；低并发、单机部署可先用 SQLite。公开注册不等于已经存在高并发，容量判断应依据测量。数据库在发布目录外，使用持久目录及独立权限；应用密钥不进入前端、Git 或发布的静态目录。SQLite 适合这类小规模单服务网站；需要多个写入实例或持续高写并发时再评估 PostgreSQL。[SQLite 适用范围](https://www.sqlite.org/whentouse.html)

现有 `scripts/serve.mjs` 是本地开发服务，含旧语音生成接口，不直接拿来充当生产账号服务。不在这台小规格机器上引入实时语音模型推理。

### D4. 微信先查资格，再决定入口

- 网站扫码登录：需要开放平台网站应用审核及微信登录权限审核；iPad 显示码、家长手机扫码是待验证方案。[官方指南](https://developers.weixin.qq.com/doc/oplatform/Website_App/WeChat_Login/Wechat_Login.html)
- 官方注册文档位于第三方平台操作指南，包含个人信息登记及未认证账号创建网页应用数量限制；它仅说明账号登记/数量限制，不能证明个人主体能获得 Website_App 微信登录权限。开发者资质认证与具体应用的 `snsapi_login` 权限都需单独核验。[平台注册说明](https://developers.weixin.qq.com/doc/oplatform/Third-party_Platforms/2.0/operation/open/create.html)
- 公众号网页授权面向微信内网页，并有认证服务号等主体限制，不能代替 Safari/PWA 登录。[服务号网页授权](https://developers.weixin.qq.com/doc/service/guide/h5/auth.html)
- 小程序的 `wx.login` 不适用于普通网页；不为登录单独再建一个小程序。[小程序登录](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/login.html)

用户已明确选择“先核实微信权限，再决定登录方式”，因此暂不选定或接入替代渠道。核验目标是个人主体能否获准网站微信登录、是否需要额外认证、具体材料及费用；不能把可创建应用数量作为获得登录权限的证据。

进一步公开文档核查结果：网站登录指南明确要求网站应用及微信登录审核通过，但未完整列明个人主体准入条件。网站应用审核规范又混有移动 App 条款，不能从其中的个人开发者例外推导网站登录获准。当前结论是“个人主体是否可获准仍未确定”，不是“已证实可用”或“已证实不可用”。官方支持询问用语：大陆个人主体，域名为同名个人 ICP 备案，无企业或个体工商户资质，能否获得开放平台 Website_App 的 snsapi_login 权限；若能，需要哪种认证、材料及费用？

本轮尝试打开 `https://open.weixin.qq.com/` 被浏览器站点安全策略拒绝，未获得后台观察权限，也未注册账号或提交申请。此限制不是微信对个人主体的审核结论；不经其他工具或浏览器绕过。公开开发文档仍可用于厘清流程，具体后台条件需用户自行查看后提供非敏感提示，或取得官方客服明确答复。

备用方案仅记录，不代表用户采纳：阿里云 PNVS 短信认证官方说明支持个人用户、免自行申请资质/签名/模板；与普通 SMS 产品不同。当前独立 API 版本小用量档（每月不超过 1000 次）为 0.06 元/计费短信，按运营商回执计费，验证码核验免费；100 条约 6 元、1000 条约 60 元，均仅为短信费用示例，不含其他服务。邮箱验证亦可候选，需先验证投递与自助恢复体验。[短信认证新手指引](https://help.aliyun.com/zh/pnvs/getting-started/sms-authentication-service-novice-guide)、[API版本计费](https://help.aliyun.com/zh/pnvs/product-overview/product-pricing)

无论最终选择微信、手机号或邮箱，账号必须能自助验证、恢复、更换凭证、退出全部会话及注销；不能以用户联系站长人工认领作为常规流程。身份验证与账号合并分开处理，不因相同昵称或用户自报联系方式自动合并存档。手机号方案还需明确换号/号码回收风险和独立恢复凭证；邮箱方案需验证控制权，不能仅因能输入该地址就创建可恢复的账号。

### D5. 本地优先，云端保存要有明确确认

- 保持本机保存成功后才推进学习状态，网络同步不阻塞练习。
- 家长能区分“已存本机”“等待同步”“已存云端/时间”“同步失败”。不能把请求发出等同云端成功。
- 首次登录先读云端并核对本机档案归属。已有本机数据由家长认领，不能默认覆盖云端；新设备的空数据也不能覆盖已有存档。
- 当前用户数据使用固定本机键。接入账号时，游客、账号、学习档案必须分区；旧游客档案只认领一次，切换账号不能重复认领同一份数据或自动上传前一人的存档。
- 首期采用带格式版本的快照与服务端 `revision` 条件更新；版本比较和写入在数据库事务内完成。重复重试不重复计入学习成果。
- 两端同时修改时保留冲突双方，暂停该档案自动覆盖，家长可选择恢复哪一份；首期不承诺无感自动合并。
- “取消掌握”和“重置”必须被保留，不能用取最大进度、true 优先或简单并集来合并。中途学习队列也不能直接拼接。
- 退出/切账号时隔离本地缓存、内存和待同步任务；旧账号的延迟响应不得写入新账号。退出过程先提示尚未上传的数据并提供处理路径。
- 不支持的格式或损坏数据保留原档并阻止覆盖。恢复前保留可回退副本；导入多模块失败时不可留下无法辨认的半份档案。
- 清除网站数据后只能恢复最后成功同步的内容；未上传的离线修改无法保证找回。

### D6. 云存档上线必须同时具备恢复和访问控制

会话使用 HTTPS 安全 Cookie、服务端鉴权、合理过期与撤销，写接口防跨站请求；密码方案使用成熟密码哈希实现。服务端依据会话确认档案归属，不信任客户端传入的账号 ID，并限制请求大小和频率。

API 和登录回调不进 SW/浏览器共享缓存，响应 `no-store`。ABC 当前不会主动缓存普通 API，但阅读 SW 会缓存作用域内部分成功 GET；三个项目接入时统一验证，不能复制 ABC 的假设。

先完成异机加密备份、保留周期、恢复演练，再把云存档作为可靠恢复能力上线。建议首期每日备份、保留最近 7 日及每周 4 份，目标故障数据损失不超过 24 小时；这是待确认目标，不是现有保证。备份位置、费用和密钥保存方式在实施时落实。

公开云存档前，落实监护人告知/同意、儿童隐私说明、数据导出和删除入口、保存期限及联系渠道；仅收必要的学习数据，不要求儿童实名/生日/照片。相关要求参照[儿童个人信息网络保护规定](https://www.cac.gov.cn/2019-08/23/c_1124913903.htm)。按实际备案主体和业务核对适用要求，不将实现这些技术措施等同于已满足全部运营义务。家长删除账号或档案后，旧设备同步和整库备份恢复都不得让已删除的档案重新出现；备份到期与删除记录的保留规则需一起设计。

### D7. 公开注册的最低运行保障

- 注册及登录验证所选凭证的控制权；验证码/恢复令牌限时、限次、一次性，校验在服务端完成；找回入口不泄露账号是否存在，恢复后撤销旧会话。参考 [OWASP账号恢复指导](https://cheatsheetseries.owasp.org/cheatsheets/Forgot_Password_Cheat_Sheet.html)。
- 按 IP、目标账号/手机号/邮箱限制注册、验证码发送、校验失败和恢复请求；异常触发额外验证，避免将单个共享网络的正常家庭永久封禁。
- 若启用外部付费验证服务，发送前预占额度，设置服务端日/月发送上限及预算告警，超时不盲目重发。平台告警不能当作硬性费用上限，具体额度待渠道确定；达到发送上限时说明暂不可验证，已有会话及本机学习继续可用。
- 限制单次存档大小、单账号容量和同步频率；不接受任意大文件或录音上传。日志不记录验证码、密钥和完整儿童档案，联系标识按需要脱敏。
- 保留暂停新注册的运维开关，避免故障扩散；与既有账号登录/恢复接口分开控制。初期用简单配置和受控命令即可，不先建设复杂管理后台。
- 正式开放前执行有限并发、越权和失败恢复验证，并监测接口错误、发送额度、磁盘及备份失败；确认账号服务压力不会阻断静态学习。

- 备案号及查询链接集中保留在统一入口首页；用户已要求三个学习页面暂不添加备案页脚。网站开通后按官方要求在 30 日内提交公安联网备案申请。[ICP备案后处理](https://help.aliyun.com/zh/icp-filing/basic-icp-service/the-icp-record-post-processing-1)、[公安联网备案](https://help.aliyun.com/zh/icp-filing/basic-icp-service/quick-start-for-public-security-network-filing-for-personal-websites)

- 暂不购买 CDN、对象存储或托管数据库。素材分发确有瓶颈时评估 CDN/OSS；数据库异机备份是单独需求，不能随“暂不买素材 OSS”一起推迟。
