# 英语小花园：完整练习闭环

本轮目标：保留原有字母课程，在同一离线网站内提供看图词汇、听音辨认、录音回听、分层阅读理解、拼词/描写/自由写作、情景对话。面向五岁初学者默认短时启蒙；后续阶段由家庭选择，不做年龄或 CEFR 自动认证。

## 验收
- 保留旧进度和课堂录音，新增记录可导出恢复。
- B、G 字母名称改用有来源的真人录音；G 字母音使用有来源的音素参考录音，仍需课堂听觉确认。
- 图片使用许可清楚的固定本地资源；公开署名、来源、改动信息；不热链。
- 词汇至少覆盖现有26例词及常用生活词。图片题不泄露答案文字；错误/帮助与独立答对分开。
- 录音仅由主动点击发起，不上传，不自动评分，离页停止麦克风，拒绝权限仍能练习。
- 阅读有文本/逐句音频/理解题；对话有分角色示范及自由表达任务；写作有描写、拼词及保存草稿。
- 有学习记录与复习入口，不把参与次数当掌握程度。
- 手机/iPad横竖屏、离线、GitHub子路径、备份、无横向溢出均验证。

## 教学范围与边界
本轮交付可运行的听说读写练习系统和原创分层内容。少量内容无法等同于“零基础至流利”的完整多年课程；高阶练习为开放式阅读、复述、表达与写作，不提供虚假的自动口语/作文评分。后续需持续扩充经教师审核的课程、授权专业音源和真人反馈。

## 结构
app/course-content.js：词库、阅读、对话、写作任务及音频清单。
app/course-core.js：独立练习证据、复习与输入校验。
app/course.js：课程页面、练习交互。
app/recorder.js：仅内存录音与释放麦克风。
assets/credits.json：第三方素材来源与许可。
