# 字母一起学

这是一条供家长陪同的学习路径。研究支持明确教学、声音与字形联系、累计复习等原则；这里的数量、时长、次数与间隔是可调的产品默认值，不代表已证实的最优处方。

## 职责与复用

- `guided-letters-policy.js`：唯一的策略默认值、边界和快照校验。
- `guided-letters-core.js`：纯状态机；注入 `now`、`random`，不访问 DOM、音频或 localStorage。
- `guided-letters-content.js`：A–Z 的亲子内容，复用现有字母基础音、例词、图片。Q 使用 qu 的 /kw/，X 使用 box 词尾 /ks/。
- `guided-letters-progress.js`：校验并恢复字母进度。与词汇进度分键保存；不认识的版本或损坏数据保留原文、阻止覆盖。
- `learning-repository.js`：字母和词汇共用的存储边界，比较原文再保存，避免多标签页旧数据覆盖。
- `guided-letters.js`：音频取消、导航、休息、保存和焦点等浏览器协调。
- `guided-session-view.js` 与 `styles.css` 的引导学习样式：单词和字母共用页头、阶段卡、底部操作与滚动约定。`guided-letters-view.js` / `.css` 只负责字母的内容和专用布局。

## 配置

```js
createLetterLearning({
  policy: {
    session: {maxLetters: 6, breakAfterMinutes: 15},
    teaching: {newLettersPerGroup: 2, maxSupportAttempts: 2},
    retrieval: {successes: 2, maxAttempts: 3, minInterveningActivities: 1},
    review: {retryAfterMinutes: 10, intervalsDays: [1, 3, 7]},
  },
  now: () => Date.now(),
  random: () => Math.random(),
});
```

家长界面仅暴露每批新字母数和休息提醒。其他设置是开发者策略参数。当前会话使用开始时保存的策略快照，修改只影响新安排；明确重学保留历史记录。

## 证据边界

名称、字母音、大小写对应分开记录。听音选择不代替独立说音，示范或跟读不计独立回想。新技能先示范再辨认，穿插后才让孩子自己说；需要帮助时回到相应技能，不强迫无限重练。只有不同日期、距最近声音曝光或上次信用至少 24 小时的独立成功才能升级跨日证据。

家长可在孩子自己说出之后播放示范巩固，再记录独立说出。首次试听前的证据边界会保留；试听按钮不会锁定评分。新字母的词音观察是教学活动，记录声音曝光但不计成绩；复习之前不先播目标答案。无声字形小游戏用来提供自然间隔，既不倒计时也不计成绩。

新的听辨题用大写辨认名称、小写辨认字母音，给初学者一个稳定的提示。名称和字母音不依赖大小写，独立回想仍会更换字形。字母音题避免同时出现同音的 C、K；没有可区分的选项时只熟悉字形，不记掌握。

范围成员变化重新安排当次会话、保留历史；范围排序不重置。今天跳过的字母次日本地零点重新可安排。刷新或切后台会暂停计时，回到页面自动接原题；主动暂停和到时休息需要家长点继续，只有到时休息后继续才开启新的时间段。

## 内容与下一步

第一版覆盖 26 个字母、听音辨认、大小写对应、独立说名称/音、熟悉词中的声音观察，以及跨日复习。声音观察由家长按说明带领，不把陌生词的理解困难计作字母错误。完整的合音拼读课未在这一版冒充为字母掌握；未来应按已学音和口头合音能力逐步扩展。

## 验证

`npm test` 包括纯引擎、存储、控制器、设置与内容覆盖。`tests/browser/guided-letters.spec.js` 跑完整路径、刷新/范围变化、设置快照、暂停预算、重学确认、保存失败、播放取消，并在手机、Pad、PC 保存各阶段截图。浏览器模拟不能替代真实 iPad 的音量、口音接受度与学习效果验证。
