# 一起学：全词库玩法检查

范围为当前 3102 个规范可学词，原始卡片 3134 张，其余为别名卡。所有词均有明确方案，缺失 0。

本次是全量程序核对、AI 语义分组复查和重点义项修订，不是 3102 份由教师逐一精修、或经过儿童验证的独立教案。

## 本次结果

- 54 种教学策略，独立于词库浏览主题；每个词在登记表中明确绑定策略、当前义项和例句快照。
- 199 个词使用具体编写的步骤或情境，2903 个词使用已归类策略并绑定自身义项、中文情境和英文例句。
- 相比调整前构建 f2dbeed62b45，3057 个词的准备／教学／听懂／迁移文本发生变化。文本变化数不等于质量评分。
- 1872 个词使用短句或情境辅助；709 个词附中文概念准备提醒；567 个词允许在图片确实直接表义时进入图片选择。
- 名词可以练命名；功能词、时态词练在短话或自然回应中使用。跟读和识别不直接计为独立表达。
- 5 岁初学者不必马上掌握所有拓展词。先检查中文概念是否熟悉；不熟时跳过，保留以后学习的路径。

## 发现与修订

1. 浏览主题不能决定玩法：手和眼睛需要指身体部位，冠词需要短语，衣物与植物部位不能当整体命名。
2. 不能按熟悉的英文同形词套义项：春天／弹簧、海浪／挥手、苍蝇／飞、火柴／比赛、遵守／观察等均按当前卡片义项处理。
3. 位置、数量、时间、次数、频率、程度、情绪和行为品质分别设计活动。左右以孩子方向为准；冠词先听熟短语，不用孩子尚不会的识字规则来考。
4. 抽象词绑定具体中文例子，功能词提供熟悉短话，不要求给抽象概念找实物，也不靠图上一个物体判断整句词义。
5. 工具、药品、疾病、危险现象采用看图或温和故事；不实际操作、制造病痛、伤害或受惊。失明／听不见采用尊重个体的支持方式介绍，不蒙眼捂耳模仿。
6. 上次未完成的旧图片题如已不适合，会转换为家长引导理解，并重听新的示范；保留已曝光提示与长期记忆记录。

## 内容源与后续维护

- 登记表：data/vocabulary/guided-word-plans.json。每个规范词恰有一条记录，义项、词性和原例句变化时必须复核。
- 专门情境：data/vocabulary/guided-scenes.json。可覆盖准备、演示、理解、回想、迁移及项目编写的短句。
- 共享玩法：app/guided-activity-profiles.js。不要重新用浏览主题自动决定语法词、抽象词和具体物的教学方式。
- 编译结果：app/guided-word-plans.js，由脚本生成。缺词、重复、未知分类、例句漂移或孤立情境会阻止构建。
- 全量核对表：data/vocabulary/guided-activities-audit.json，逐词列出分类、义项、准备、情境和示范短句。指令哈希只用于检测变化，不是教学质量认证。
- 原单词音频保持使用录音。情境示范优先复用相同例句的已有音频规则；新编短句使用家长所选英文系统音色和语速，不伪装成已有录音。
- 本地修改中文义项后，不自动套用原义项的专门玩法；改用家长确认的情境。已有例句署名在展示时保留。

验证命令：

```sh
node scripts/compile-guided-activities.mjs --check
npm run audit:guided
npm test
npx playwright test tests/browser/guided-words.spec.js --project=iPad-chromium --project=iPad-webkit --project=phone-chromium
```

这些检查验证覆盖、内容绑定、出题与播放流程；真实 iPad 发音、家长是否容易操作及儿童学习效果仍需实际使用确认。
