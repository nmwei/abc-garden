## 维护方式

1. 固定基线 ID 保留在 context-completion-plan.json，追加批次，不重建基线。
2. 每张图记录释义、词性、双语例句快照和设计说明；内容变化后必须重新核对。
3. 修改 context-recipes.tsv 或第一批设计 → node scripts/generate-context-symbols.mjs → node scripts/plan-context-recipes.mjs → node scripts/generate-context-pictures.mjs → 编译词库 → 按需生成音频 → npm run build → npm run audit:completion。
4. 使用浏览器检查图片解码、缩略图语义、选词与离线播放；每批记录实际验证证据。
